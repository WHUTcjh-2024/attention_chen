## 编辑思维导图

在 Windows 上双击 [编辑导图.cmd](./编辑导图.cmd)。浏览器会打开本机编辑页：

1. 左侧选择节点，右侧修改标题和说明，或新增、移动、删除节点。
2. 点“保存草稿”后，可用“打开预览”检查效果。
3. 点“保存并发布”会只提交导图数据，并推送到 GitHub `main`。GitHub Pages 随后自动更新。

编辑器只监听 `127.0.0.1`，不需要在网页里填写 GitHub 令牌。电脑需要有 Node.js，以及可正常推送该仓库的 Git 登录状态。关闭启动编辑器的命令行窗口即可停止服务。
